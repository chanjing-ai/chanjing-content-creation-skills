## 各产品在哪（`products/`）

| 文件夹 | 干什么 |
|--------|--------|
| `chanjing-credentials-guard` | 配 AK/SK、看状态、拿 token |
| `chanjing-tts` | 配音、合成 |
| `chanjing-tts-voice-clone` | 声音克隆再合成 |
| `chanjing-avatar` | 对口型 / 数字人视频 |
| `chanjing-video-compose` | 合成视频、上传、下载 |
| `chanjing-customised-person` | 定制数字人 |
| `chanjing-text-to-digital-person` | 文生形象、动作等 |
| `chanjing-ai-creation` | 通用 AI 创作任务 |

每个目录里：**说明书** = 同名 `*_SKILL.md`；**脚本** = `scripts/`。想列能力可以跑 **`scripts/cli_capabilities.py`**，具体参数以说明书和 **`脚本 --help`** 为准。

## 本机试跑前要准备啥？

1. 用 guard 配好 **`~/.chanjing/credentials.json`**（或自己设 **`CHANJING_CONFIG_DIR`**）。  
2. 一键成片找不到仓库时，设 **`CHAN_SKILLS_DIR`** 指向这个 git 仓库的根目录。  
3. 成片要装 **`ffmpeg`、`ffprobe`**（要系统里有命令，不单靠 pip）。  

更细的表在包根 **`SKILL.md`**。
